# Reactjs Food Order

1. Make sure you have installed NodeJS
2. Clone the repo
```sh
git clone https://github.com/aiden-takeda/reactjs-food-order.git
```
3. Install packages
```sh
npm install
```
4. Add env if using nodejs newest than 18.20.4
```sh
# Linux
export NODE_OPTIONS=--openssl-legacy-provider

# Windows
$env:NODE_OPTIONS="--openssl-legacy-provider"
```
5. Start local web server
```sh
npm start
```
